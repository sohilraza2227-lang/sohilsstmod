Sohilsstmod.com website starter

1. Open index.html in a modern browser to preview.
2. Upload apps from the Owner Upload Panel.
3. This starter stores uploaded files in the current browser's IndexedDB only.
   It does NOT publish uploads to other visitors or provide secure owner authentication.
4. To make it a public app-download website, deploy the frontend and connect a backend
   (database + file storage + secure admin login). Do not treat a hidden frontend panel
   as security.

You can host the static page on GitHub Pages, Netlify, or another static host, but
shared uploads require the backend described above.
